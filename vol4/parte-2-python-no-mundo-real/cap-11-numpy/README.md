# cap-11-numpy

Exemplos, exercícios e gabaritos deste capítulo. A pasta é um projeto **independente**.

```bash
uv sync                      # cria o ambiente deste capítulo (Python 3.15)
uv run python exemplos/<arquivo>.py
uv run pytest                # corrige os seus exercícios
```

| Pasta | Conteúdo |
|---|---|
| `exemplos/` | código mostrado no livro |
| `exercicios/` | esqueletos para você completar |
| `gabaritos/` | soluções (tente antes de olhar!) |
| `tests/` | testes que corrigem o exercício |

Para validar os gabaritos: `CHECK_GABARITOS=1 uv run pytest`.
